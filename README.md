# UNDEADHEAVEN S.T.A.L.K.E.R. — конструктор билдов из артефактов

Интерактивный калькулятор артефактов для сервера **[RU][PVE] UNDEADHEAVEN S.T.A.L.K.E.R.** (DayZ).

**👉 Открыть конструктор: https://frolik34.github.io/undeadheaven-artifacts/**

## Возможности

- 📦 Каталог из 92 артефактов — у каждого класснейма свои статы
- 🎒 10 слотов как в экзоскелете: клик по арту — добавить в билд
- ⚡ Живой расчёт итогов (без кнопок): HP, кровь, стойкость, еда, вода, выносливость, радиация, прыжок, скорость, защиты
- ☢️ Анализ радиации и предупреждения (голод, жажда, переломы, кровотечения)
- 🔍 Поиск и фильтры: Выживание / Вывод радиации / Защита / Мобильность
- ⏱ Переключение «за тик (3 сек)» / «за минуту»
- 💾 Сохранение сборок в браузере
- 🔗 Ссылка на билд — скинь другу, у него откроется твоя сборка
- Всё считается в **целых числах**, без процентов

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Конструктор билдов (страница) |
| `арты_база.js` | База статов для калькулятора |
| `bg1.jpg`, `bg2.jpg` | Фон в стиле загрузочных экранов сервера |
| `balance.json` | Все статы: правятся в любом текстовом редакторе |
| `_rebuild.py` | Пересборка `global.json` и базы калькулятора из `balance.json` |
| `global.json` | Готовый конфиг артефактов для мода сервера |

## Правка баланса

1. Открой `balance.json` в Блокноте — у каждого класснейма свои статы, только целые числа.
2. Запусти `python _rebuild.py` — пересоберутся `global.json` и база калькулятора.
3. Обновлённый `global.json` положи в конфиг мода на сервере.

### Единицы (очки игрока за тик, тик = 3 сек)

HP ×1 | Кровь ×4 | Стойкость ×8 | Еда ×5 | Вода ×5 | Выносливость ×4 | Радиация ×7 (+накопление/−вывод) | Прыжок = 45 за очко | Скорость = 10 за очко | Защиты ×1

Флаги: `brok` — шанс перелома, `bleed` — вызывает кровотечение, `hbl`/`hbr` — лечение кровотечения/перелома, `fall` — сопротивление падению, `punch` — отбрасывание.
